# Готовые тексты для заполнения заявки (Direct API)

## 1) Техническое описание приложения (готовый вариант)
Приложение взаимодействует с Яндекс.Директ API версии 5 в формате JSON по протоколу HTTPS (POST).

Авторизация выполняется через OAuth 2.0: в каждом запросе передается access token в заголовке `Authorization: Bearer <token>`.

Дополнительно в запросы передаются обязательные заголовки:
- `Client-Login: <логин Директа>`
- `Accept-Language: ru`
- `Content-Type: application/json; charset=utf-8`

Для большинства сервисов запросы выполняются в форме:
`{ "method": "<methodName>", "params": { ... } }`

Для сервиса `reports` используется JSON-структура с параметрами отчета:
`{ "params": { /* ReportDefinition */ } }`

Отчеты обрабатываются в онлайн/офлайн режиме:
- при HTTP 200 отчет возвращается сразу (TSV),
- при HTTP 201/202 отчет формируется в очереди; запрос повторяется через интервал `retryIn` (если указан в заголовках ответа).

## 2) Для чего предназначено приложение (готовый вариант текста)
Приложение предназначено для автоматизации управления рекламными кампаниями и получения статистики в Яндекс.Директ через официальные методы API.

Возможности приложения:
- создание и изменение сущностей (кампании/группы/объявления/ключевые фразы/ставки и корректировки),
- получение параметров и статусов объектов,
- управление доступностью (остановка/возобновление/архивация при необходимости),
- получение отчетов со статистикой по заданным критериям (онлайн и офлайн режимы).

## 3) Какие новые возможности работы с Директом дает приложение (готовый текст для textarea)
Приложение расширяет возможности работы с Яндекс.Директ за счет автоматизации рутинных действий и интеграции управления и аналитики.

Благодаря обращению к API по OAuth токенам:
- снижается нагрузка на оператора при регулярных задачах (обновление ставок/параметров, чтение статусов),
- ускоряется получение статистики и отчетов (включая офлайн формирование),
- появляется возможность строить процессы на данных из Директа (BI/аналитика/внешние системы) и использовать их для принятия решений по бюджетам и ставкам.

## 4) Подтвердите схему взаимодействия с Директом (готовый текст)
Взаимодействие осуществляется от имени пользователя через OAuth access token:

1. Пользователь предоставляет приложению доступ к своим данным в Яндекс.Директ (OAuth flow).
2. Приложение получает access token и использует его для авторизации в каждом запросе.
3. Приложение выполняет вызовы к Direct API (v5/v501 JSON), передавая корректный `service`, `method` и `params` (или только `params` для `reports`).
4. Ответы приложения обрабатываются: для `reports` результат используется в формате TSV, для операционных методов — результаты действий (created/updated/retrieved и т.п.).
