# Пакет материалов для заявки на доступ к Яндекс.Директ API

## Какие файлы приложить
1. `registration_screenshot.png` — скриншот формы “Заявка на получение полного доступа к Яндекс.Директ”.
2. `SPECIFICATIONS_API.md` — техническая спецификация: OAuth, URL, форматы запросов (включая `reports`).
3. `FORM_READY_TEXTS_RU.md` — готовые тексты для полей заявки (техническое описание, назначение, новые возможности, схема взаимодействия).

## Важно
- В тексты НЕ вставляйте access token / пароли / секреты.
- В поля, где требуется `application_id`, `company`, `site` и логины Директа, подставьте ваши реальные значения.
